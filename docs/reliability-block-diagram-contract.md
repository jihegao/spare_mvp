# 装备可靠性框图绘图契约

本文档固定 `任务可靠度评估模块 / 仿真建模 / 装备系统建模 / 装备可靠性框图建模` 的当前绘图要求。修改 `front/rbd-evaluator.mjs`、`front/app.js`、导入样例或装备树选择逻辑时，必须同步更新本文档和对应测试。

## 数据来源

- 左侧树复用装备组成树，选择状态来自 `resolveSelectedEquipmentNode()`。
- 绘图输入优先读取 Project 中的 `reliabilityBlockDiagram`，并用 `components` 补齐节点名称、失效率、MTBF、RMS 可靠度、数量和 `kOutOfN`。
- `reliabilityBlockDiagram` 是 clean Project 的正式建模输入；保存时只剥离画布坐标等 UI 字段，必须保留节点、连线、串并联关系和可靠性参数。
- 显式 reliabilityBlockDiagram 只有顶层节点时，组件下钻必须回退/融合 components 的真实直接子级，不能停留在通用顶层 RBD 节点。
- 缺少可绘制节点时，右侧显示空态，不从静态 demo 数据静默补业务样例。

## 选择范围

- 选中 `飞机列表` 根节点时，右侧不显示任何框图内容。
- 选中整机或组件时，只显示当前选中节点的直接下一级节点，不显示当前选中节点自身。
- 选中整机时，展示该机型全部顶层系统，例如 J-15 展示 `发动机`、`航电系统`、`液压系统`。
- 选中组件时，展示该组件下一级，例如 J-15 > 发动机 只展示 `发动机控制模块`。
- 如果直接下一级为空，右侧显示空态，而不是重复显示当前节点。

## 绘图语义

- 串联节点按主线顺序连接。
- 备用关系按备用样式展示，但仍作为主线阶段参与连接。
- 门逻辑节点保持独立展示，不折叠成普通组件。
- `n中取k` 节点按并联冗余结构绘制：标签显示在外层并联框上，格式为 `并联 / 2中取1`、`并联 / N中取K`。
- `n中取k` 外层并联框内展开 N 个同名分支节点，左侧从入口分流，右侧汇合到出口。
- `n中取k` 标签不能写在单个组件框内部；组件框内部只显示分支编号，例如 `分支 1/2`。
- 即使当前选择结果只有一个 `n中取k` 节点，也必须展开外层并联框和 N 个分支，不能把单节点当作 root 跳过展开。

## 表格语义

- SVG 节点可以为了画并联分支而复制，但逻辑表格只保留一行原始节点。
- 表格的 `n中取k / k-out-of-n` 列显示逻辑节点的 `2中取1` 等标签。
- 表格不得因为可视化分支复制而出现两行同名逻辑节点。

## 当前样例验收

- `飞机列表`：右侧不显示任何框图内容。
- `J-15`：展示 `发动机`、`航电系统`、`液压系统`，不展示整机根节点；`发动机` 和 `航电系统` 的 `2中取1` 画成外层并联框，`液压系统` 画在主线上。
- `J-15 > 发动机`：只展示 `发动机控制模块`，按串联样式绘制，不展示父级 `发动机`。
- `J-35 > 航电系统`：只展示 `任务计算机模块`；该节点 `2中取1`，必须画成 `并联 / 2中取1` 外层并联框，并展开两个 `任务计算机模块` 分支。

## 测试锚点

- `tests/rbd-evaluator.test.mjs` 固定 RBD 投影、直接下一级选择、`n中取k` 外框/分支、逻辑表格去重和导入样例验收。
- `tests/aircraft-mission-reliability.test.mjs` 固定任务时长产品可靠度、串联/并联/n 中取 k 逐级计算、层级明细和失败关闭校验。
- `tests/frontend-contract.test.mjs` 固定前端页面入口、字段、选择属性和本文档关键条款。

## 飞机任务可靠性分析

- “结果分析 / 飞机任务可靠性评估”与 Mesa“任务可靠度评估”是两个独立口径，前者计算产品结构可靠度，后者统计完整任务周期实验成功比例。
- 叶产品根据任务时长和失效率、MTBF 或失效分布计算可靠度；串联系统取子节点可靠度乘积，并联系统取 `1 - ∏(1-Ri)`，n 中取 k 使用至少 k 个分支成功的概率。
- 关系、参数或单位缺失/非法，任务时长无效，或者框图存在重复、孤立、无效引用和循环节点时，不得生成分析结果。
- 保存历史时固化飞机型号、任务剖面、任务时长、框图和逐节点结果；后续修改建模数据不改变已有快照。
