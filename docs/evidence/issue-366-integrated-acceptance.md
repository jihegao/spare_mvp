## 当前工具的独立页面验收（Issue #376，待实跑）

`scripts/issue-366-browser-acceptance.mjs` 现逐个点击五个原页面的“运行分析”按钮；产品不承担批量验收逻辑。工具只连接已经启动的隔离服务。环境变量为 `BASE_URL`、`ACCEPTANCE_USER`、`ACCEPTANCE_PASSWORD`、`TESTED_SHA` 和仓库外绝对路径 `RESULT_DIR`。默认选择唯一 F35 项目，其他项目通过 `PROJECT_NAME` 精确指定。

默认通过现有实验方案管理界面新增专用方案，配置 50 样本、8 核、固定种子并保存、冻结；这会在隔离库中新增方案，不能连接用户生产服务执行。`PLAN_NAME` 可精确指定已有冻结方案，此时不创建或修改方案。同名或参数不是 50/8 均失败退出。四原分析页的当前项目模式默认 4 样本且没有样本输入，因此工具使用同一冻结方案的权威参数，不注入应用状态、修改请求或添加第二个 Project 编译入口。

五个原页面分别导航、选择方案、点击原运行按钮，逐项要求新的唯一请求、HTTP 200、50 完成/0 失败、8 worker、正确分析类型及项目/冻结方案/指纹一致；五个 session 不同。冻结请求不携带客户端 settings 覆盖。计时从真实按钮 click 事件开始，直到该页面成功状态、非占位数据出现并完成两次 animation frame，每项独立 ≤60 秒。蒙特卡洛验证本页指标；其余四页验证明细及导出按钮可用。工具计时、响应元数据和结果计数写入仓库外私有报告，原始数据和凭据不落盘；截图仅在明确指定仓库外 `SCREENSHOT_DIR` 时保存。

远端原生 Edge 可由操作者启动本任务专属 profile 与调试端口，再用隧道提供 `CDP_URL`。工具通过 CDP 新建自己的隔离 context/page，结束只关闭该 context 并退出客户端进程，不发送关闭远端浏览器命令。远端模式禁止 `PLAN_NAME` 复用，必须从当前 F35 项目通过 UI 新建并冻结 50/8 方案。报告记录浏览器版本和连接模式；`display_seconds` 使用浏览器自身时钟，SSH/CDP 往返不计入按钮至绘制耗时。Node 侧元数据采集耗时单列，不能替代页面计时。

工具中的 F35 验收要求非空行；合法零需求或零事件的其他模型不自动视为同一验收数据集。导出按钮可用不代表本轮验证了生成文件内容。下方历史报告保持原值；新的 V2 五原入口报告必须在合并完成后独立实跑，当前尚无该结果。

目标 4700-4 的 Windows 版本未部署或复验，本机结果不能替代目标环境验收；本记录不关闭 #366。
