## 浏览器核对结论

- 项目列表卡片当前只显示 `进入 / 编辑 / 删除`，没有每个项目独立的项目 JSON `导入 / 导出` 按钮。
- 当前系统模块仍命名为 `系统管理`，尚未改为 `系统运行支持模块`。
- `系统管理 / 项目管理 / 数据管理` 当前仍管理通用项目数据行，并显示 `建模数据 / 实验配置 / 实验结果` 页签；尚未改为按仿真建模模块选择 sheet 页的矩阵。
- `系统管理 / 项目管理 / 建模颗粒度管理` 当前显示 `建模层级 / 建模对象 / 对象关系 / 操作`；尚未改为 sheet/字段级勾选配置。
- `系统管理 / 项目管理 / 建模数据导入` 仍作为独立页面存在。
- `装备RMS指标分配` 当前包含 `装备组成树`、`指标输入与方法设置`、`校核与摘要`、`节点级分配结果`、`任务暴露矩阵`，方法包含 `AGREE 分配法 / 评分分配法`；尚未符合“顶部参数、左侧装备树、右侧方法选择与计算、底部节点分配结果”的目标布局。

- `装备系统建模` 仍有 `装备组成建模` 和 `装备故障建模` 两个四级页签。
- 保障资源页面仍包含 `适用机型` 和 `操作` 列；保障人员、保障设备、备件页面尚未提供页面局部导入按钮。

## 阶段与优先级调整

- 当前阶段优先做建模页面本身的收敛，不启动系统管理相关重构。
- `系统管理` / `系统运行支持模块` 相关事项统一后移到当前阶段结束之后再开始，包括项目数据管理、建模颗粒度管理、独立建模数据导入页删除、用户管理、功能权限管理、建模表单管理。
- 项目列表项目 JSON `导入 / 导出` 暂缓，不进入当前阶段。
- `装备RMS指标分配` 页面重构移入当前阶段，作为当前阶段并行实施项。
- `装备组成建模` 与 `装备故障建模` 合并为一张 `装备系统建模` 表优先级为高，是当前阶段主线。
- `仿真实验方案管理` 后移到下阶段实现，不进入当前阶段。
- 当前阶段另需明确两类页面交互规则：
  - `复合任务建模` 中从 `基本任务` 带过来的属性全部不可编辑。
  - `保障组织建模`、`保障活动建模` 页面上的表格数据应支持直接编辑；关联其他对象属性的字段用下拉控件，名称类字段用文本框。
