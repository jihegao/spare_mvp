# 分析结果与会话导出契约

本文固定 #385、#394–#403 的当前实现边界。Project 结构和模型输入不变，编译继续经过 repository、`ProjectJsonExporter` 和唯一 `SimulationAdapter`。

## 导航与错误

导航按“模块＋二级栏目”保存展开状态，重绘、自动保存、列表刷新和轮询均保留；活动栏目始终展开。四个共用分析页只在结果区显示一次错误，保留运行重试及本人任务恢复。单重任务门禁不变，不泄露其他用户任务。

只有实际建模校验失败显示“建模粒度不足”。任务占用、全样本超时、执行失败、网络失败、结果过期分开表达，稳定错误码见 `simulation-tasks.md`。部分样本失败继续展示已完成结果及失败统计。

## 备件指标与携行清单

蒙特卡洛卡片、统计表及 Excel 中的比例均值统一显示两位小数百分比；真实零值显示 `0.00%`，大于零但不足 `0.01%` 时显示 `<0.01%`，避免低利用率被误读为没有消耗。方差仍按原始 0–1 比例计算并保留四位小数，比例指标的单位栏明确为“均值：%；方差：比例²”。例如消耗 1 件、初始携行 501 件时显示 `0.20%`。

蒙特卡洛页面和 Excel 使用“备件满足率”“备件利用率”，保留实际数量来源、有效样本数、均值、n−1 方差及零分母处理；移除跨样本总体比率、维修积压和逐样本备件明细。内部原始字段继续兼容，不能用展示删减改变算法。

携行清单的两种入口共用实际数量归一化。数值零和有效数字字符串零可以被零需求过滤隐藏；空值、布尔值、非法值和缺失字段保持“数据不可用”。机型、零需求和排序先作用于完整结果，再分页，筛选变化回到第一页，Excel 导出全部筛选行。规划满足率和单独阈值不展示，约束按原始实际比例比较，余量使用百分点；总体数量比仍保留原有携行清单口径。

## 停机事件

直接原因优先级仍为：备件短缺、保障设备短缺、装备故障、预防性维修。同一飞机的同一时段只归一个因素；等待备件和实际维修分段累计，次数按段计算。组织备件原因仅明确匹配：

- `organization_no_available_ancestor`
- `organization_no_available_supplier`
- `organization_no_vertical_path`
- `organization_no_supply_path`

不泛化全部 `organization_*`。不增加无库存启动警告，无库存结果按实际等待及后续轨迹输出。

canonical 账本保存分段结束原因、结束时状态和具体短缺原因。同一因素内原因变化更新结束时事实，不增加分段次数。等待转维修显示“等待结束，转入维修”；只有真实维修完成才填写修复时间。故障截止显示“未修复·仍等待备件／调拨／维修”，结束时间标明“仿真截止”；非故障保障作业显示“未完成”。计划到货与实际观测到货区分，截止不伪造等待完成或到货。

页面、汇总、占比及 Excel 都来自账本；明细提供真实样本编号、随机种子、机号、结束状态及“该段累计停机时长”。样本、种子、状态与因素筛选组合生效。方式说明依据实际执行方式和有效备件需求，非换件不显示“LRU 自动换件”，不改写用户保存的方案名称。

业务决定动力装置改为 LRU，但案例产品类型、库存及冻结方案属于独立数据调整，本轮通用代码不迁移。

## 任务可靠度明细与趋势

样本选项只取明细已有 `sampleIndex`，内部零基、显示加一，不按行号补造身份。选择样本只过滤已有明细，不启动分析；普通重绘保留选择，结果上下文变化恢复全部。

波次曲线按 `dayIndex + waveIndex` 聚合全部样本已有有效成功率，采用算术平均。1/1 与 0/9 两个样本的曲线值为 50%，不是合并计数的 10%。缺失和非法值排除，横轴保留完整业务波次；纵轴固定 0%–100%、每 20% 一格。Tooltip 显示两位小数均值、有效数、总样本数和排除数。

正式 projection 的趋势总样本数取 `data.total_samples`（归一化字段 `totalSamples`），该波次缺失明细的样本也计入总数和排除数。例如总计 100 个样本、某波次仅 2 个有效值时，提示为有效 2、总数 100、排除 98。

明细筛选不改变总体摘要或趋势。Excel 明细采用当前样本范围且导出全部筛选行，并标注摘要仍为全部样本口径。

## 来源与导出

服务端结果绑定运行时项目及实验身份和显示名称，恢复和导出沿用结果来源。蒙特卡洛文件名为 `项目名-实验名-蒙特卡洛分析-YYYYMMDD.xlsx`；直接运行当前项目时，实验段为“当前项目”。日期取客户端本地日历日期，保留中文和空格，替换 Windows 非法字符。下载响应、实际文件名及页面提示一致。

停机导出使用任务引用，从本人已完成会话读取完整账本并先筛选后汇总。每表 10,000 条，总限 100,000 条、40 列、64 MiB 单元格文本及 64 MiB 文件；超限完整拒绝。普通请求仍限 1 MiB，导出等待 120 秒。任务完成 30 分钟后或服务重启不可用，不自动重跑，不回退上传事件。请求契约和错误见 [`simulation-tasks.md`](simulation-tasks.md)。

## 实验名称与界面状态

实验名称去首尾空白后大小写敏感，只在当前数据库同项目查重，全部有效状态及其他用户的同项目方案均参与；跨项目允许同名。新建或改名冲突返回 HTTP 409 / `experiment_plan_name_conflict`。历史重名不批量改名，名称未变草稿允许保存，冻结方案不可修改。

查重、必要快照创建和方案保存处于同一个 SQLite `BEGIN IMMEDIATE` 写事务。新建使用 INSERT，不通过 upsert 覆盖已有记录；失败完整回滚，不遗留快照。不添加会使历史重名升级失败的全量唯一索引。前端即时提示并保留输入，后端执行最终校验。

新建或更新实验方案引用不存在的 `modeling_snapshot_id` 时，返回 HTTP 404 / `modeling_snapshot_not_found`；请求失败不新增快照或方案，也不修改已有方案。

框图视口、调宽、缩放与滚动状态见 [`reliability-block-diagram-contract.md`](reliability-block-diagram-contract.md)，所有操作只修改会话界面状态。
