## 1. 验收边界

本清单用于评审前检查当前静态前端 MVP。当前验收只覆盖页面结构、演示交互、模拟数据展示、CSCI 完整部件入口和响应式表现，不覆盖后端接口、真实仿真计算、数据持久化、真实运行调度或 `core/` 仿真内核。

页面中的结果数据来自 `front/app.js` 内置常量。“启动”按钮仅触发模拟启动反馈和最近启动时间展示，不代表真实计算完成。

旧版前端和建模实现不进入本轮验收。当前验收以新的前端原型页面和字段为准，后续后端仿真算法应在单独阶段通过 TDD 对齐这些字段。按功能页计，当前前端包含 9 个 CSCI-MVP 页面；若把首页导航也计入可访问页面，则共 10 个页面。

## 11. 评审前检查命令

当前为纯静态页面，可直接打开 `front/index.html` 进行人工检查。若需要本地 HTTP 服务，可在仓库根目录执行：

```bash
python3 -m http.server 8000
```

然后访问：

```text
http://localhost:8000/front/
```
