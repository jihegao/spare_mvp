# RMS 指标分配方法与当前实现

## 当前边界

装备 RMS 指标分配是系统运行支持模块下的本地份额分配工作台。飞机型号来源于当前 Project 的装备系统建模；选择机型后，页面只投影该机型的装备结构。安装数和运行比仍是 RMS 工作台编辑值，不回写装备系统建模中的 MTBF/MTTR 字段。

当前页面不再提供反算模块。计划、结果、页面和 XLSX 导出均不包含目标 R、校核可靠度、MTBCF、MTBF 或 MTTR 裕度。工作台只保留计算和导出，不提供独立的保存或发布按钮；机型选择、四项 RMS 输入、树选中状态、工作台装备值和结果会按机型写入 Project draft 的 RMS 过程字段，并在正式 Scenario 编译前剥离。

## 页面结构

页面按以下 DOM 与视觉顺序组织：

1. “飞机型号与 RMS 输入”区块，包括任务可靠度、任务时长、关键故障占比和 MTTR。
2. 左侧当前机型“装备结构树”和右侧“导入安装数”。导入表展示系统名称、型号、安装数、运行比；下载模板与上传文件按钮尺寸一致。
3. 独立“计算方法”区块。
4. “节点分配结果”区块及真实 XLSX 导出。

导入模板字段为节点 ID、父节点 ID、系统名称、型号、层级、安装数和运行比。导入数据只更新 RMS 工作台内存状态。

子系统安装数必须是正整数；运行比必须是 `0..1` 的有限数。缺失或非法值会拒绝整次导入，不做默认值补齐、四舍五入或截断。运行比可以为 0，但比例法或相似产品法的全部节点权重为 0 时计算失败，不产生“已分配”结果。

## 分配契约

`rms-allocation-plan-v3` 声明四项 RMS 输入、分配方法及其参数。计算前必须选择飞机型号，并校验任务可靠度 `(0, 1]`、任务时长 `> 0 h`、关键故障占比 `[0, 1]`、MTTR `>= 0 h`。`rms-engine-3.1.0` 的结果同时记录当前飞机型号和输入快照，每个节点结果固定包含：

- 层级、节点、型号；
- 安装数、运行比；
- 分配份额、状态。

全部节点的分配份额归一化后合计为 1。等分配法按系统节点等份；比例分配法按安装数、运行比和已有工程因子形成权重；相似产品分配法按所选基准机型对应节点的安装暴露形成权重。比例法与相似产品法不提供全局修正系数，因为统一乘数在归一化后不会改变份额。相似产品基准必须存在、不能是当前装备，并且必须能为每个目标节点找到同名对应节点；否则计算失败关闭。该结果是分配建议，不是可靠性反算或工程校核结论。

## Excel 导出

前端把页面正在展示的节点结果原样提交到 `/api/rms-allocation/export-xlsx`。后端用 `openpyxl` 生成真实工作簿，结果表头顺序与页面一致：层级、节点、型号、安装数、运行比、分配份额、状态。
