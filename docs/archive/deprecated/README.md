# 过期文档归档

本目录保存已经退出当前开发面的历史文档。归档文档用于追溯设计来源、阶段讨论和一次性审计，不再作为默认实现依据。

## 归档规则

1. 活跃文档层只保留总路线图和当前开发面。
2. 阶段计划、阶段规格、原始需求转换稿、一次性审计和已被当前实现替换的方案放入本目录。
3. 修改当前实现时，优先阅读 `docs/README.md`、`docs/product-roadmap.md` 和对应当前开发面文档；只有需要追溯历史决策时才阅读本目录。
4. 归档文档可以保留当时的旧路径、旧术语和旧非目标；不要把这些内容重新提升为当前契约。
