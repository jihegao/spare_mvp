# 当前 PR 相对 `origin/main` 的变更说明

> **状态：已过期，归档于 2026-06-20。**
>
> 本文档记录 `codex/modeling-list-action-hardening` 分支相对旧 `origin/main` 的临时 PR 变更说明。该分支上下文已经过期，不再作为当前产品路线、验收口径或实现计划依据；保留在归档目录中仅供历史追溯。

本文记录当前 PR 分支相对 `origin/main` 的主要前端建模调整。

## 分支范围

- 基线分支：`origin/main`
- 当前分支：`codex/modeling-list-action-hardening`
- 覆盖提交：`ae627129`、`0d768f23`、`d7ffc499` 及评审修复提交。
- 本说明覆盖备件规划前端建模页对齐、列表动作展示边界和支援活动岗位删除能力。

## 功能导航与页面结构

- 将原“装备建模”调整为“装备系统建模”，保留装备组成、装备故障、装备可靠性框图等系统级页面。
- 将原“任务建模”调整为“装备任务建模”，移除“内置场景”和“任务剖面参数”四级页。
- 装备任务建模顺序调整为：基本任务建模、复合任务建模、周期性任务建模、基本作战单元建模。
- 在两个业务模块的“保障活动建模”下新增“后勤保障活动建模”页。
- 页面总数从基线的 55 页调整为 52 页。

## 仿真建模前端能力

- 新增可展开/收起的通用结构树组件，用于任务、装备、保障组织、保障活动等结构树。
- 基本任务结构树改为“飞机类型 -> 基本任务”的父子结构。
- 基本任务的任务成功点改为 0 到 1 的小数输入，去掉出发时间和更新时间展示。
- 复合任务中的“首波次出动时间”改名为“出发时间”。
- 周期性任务建模增加列表、新增、删除、选择和周期任务编辑能力。
- 装备系统建模支持整机级型号案例：`F35`、`F15`。
- 装备组成建模参照 `ship_front` 装备构型页，支持按“飞机 -> 分系统 -> 子系统/LRU”递归选择和新增节点。
- 装备组成建模的产品类型改为可配置选项：`LRU`、`SRU`。
- 已接入状态变更的列表动作为新增/删除基本任务、复合任务、复合任务条目、作战单元成员、周期性任务、后勤运输策略，以及保障活动岗位单条/批量删除。
- 未接入保存契约的新增、编辑、删除入口保持禁用状态，避免出现可点击但无效的控件。

## 保障组织与保障活动调整

- 保障组织建模去掉运输相关展示和字段，不再在组织详情中维护运输策略。
- 保障组织页面保留组织树、组织详情、备件/人员/设备资源表。
- 所有保障活动页面移除网络图。
- 使用保障活动建模去掉“仿真运行规则”“加油方案”“挂载方案”。
- 后勤保障活动建模改为运输策略配置页，不再显示左侧活动树、方案类型、保障组织策略表和工作项目清单。

## 后勤保障活动建模

后勤保障活动页集中配置保障组织之间的运输策略，每条策略支持：

- 策略方向：横向运输 / 纵向运输
- 备件种类：从备件建模同源数据中读取，即保障节点库存里的备件名称集合
- 触发方式：临界库存 / 周期性调运
- 触发参数：
  - 选择“临界库存”时配置“临界库存数”
  - 选择“周期性调运”时配置“调运周期(h)”
- 运输起点
- 运输终点
- 运输时间(h)

默认案例数据包含两条后勤运输策略：

- 纵向运输：发动机备件，临界库存触发，配置临界库存数
- 横向运输：航电模块，周期性调运触发，配置调运周期

## 案例数据更新

- 装备整机级案例从单一机型扩展为 `F35`、`F15`。
- 装备组件数据增加所属飞机和父节点层级，默认案例支持 F35/F15 各自的分系统与子系统树。
- 作战单元成员、任务、维修活动、保障活动树同步更新为上述机型。
- 支持活动案例中移除后勤保障工作项目清单，后勤仅作为运输策略配置数据。
- 后勤运输策略中的备件名称与备件建模的库存备件名称保持一致。
- 支援活动岗位表支持选择后单条删除和批量删除。
